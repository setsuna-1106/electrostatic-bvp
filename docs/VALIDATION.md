# M1 数值验收

M1 验收覆盖 `rectangle_sine`：二维无电荷 Laplace 方程、均匀正方网格、固定 Dirichlet 边界、五点差分和 Jacobi 迭代。下方另记录平行板 S1–S3 的功能检查；它们不代表平行板的网格、迭代或计算域敏感性已经通过验收。

## 复现

从项目根目录运行：

```bash
uv sync --locked
PYTHONPATH=src uv run --locked python -W error -m unittest discover -s tests -v
PYTHONPATH=src uv run --locked python -W error scripts/validate_m1.py
```

单元与端到端测试由标准库 `unittest` 执行，数值验收脚本遇到任一检查失败即返回非零退出码。`-W error` 使计算中的浮点警告也会导致本次核验失败。

验收脚本将默认算例、三档网格、三档停止阈值及最大迭代停止算例分别写入 `results/m1-validation/`。顶层 `report.json` 保存输入配置、检查项、误差、观察阶数、Python/NumPy 版本及源码 SHA-256，便于核对所用实现。原始数组和报告不纳入 Git，版本库保存复现所需的代码与说明。

## 验收内容

| 层次 | 检查方法 |
|---|---|
| JSON 接口 | 格式化脚本与配置读写往返；缺失/多余字段、非法类型、非有限参数、网格不可整除与不支持的算例均拒绝 |
| 网格与边界 | 最小 3×3 节点网格、零/负电压；固定四边、左右对称性和离散最大值原理 |
| Jacobi 更新 | 用一次迭代的手算结果排除原地更新；分别验证达到 `tol`、达到 `Nmax` 和最后一次迭代恰好达到阈值 |
| 方程与误差 | 独立计算内部离散 Laplace 残差；核对内部最大误差/RMSE；与离散精确模态比较以分离迭代误差 |
| 电场 | 以已知梯度的二次多项式检查负号、坐标轴和边界；与连续解析电场比较全网格向量误差 |
| 网格加密 | 固定几何与电压，使用 `h=0.1, 0.05, 0.025` 和 `tol=1e-11`；检查电势与电场误差的观察阶数在 1.8–2.2 内 |
| 停止阈值 | 默认网格使用 `tol=1e-6, 1e-8, 1e-10`；阈值收紧应增加迭代次数、减少相对离散精确解的误差 |
| 数值稳定性 | 普通矩形的稳定解析式与直接双曲正弦式一致；纵横比 300 的算例不产生溢出或非有限输出 |
| 输出与退出码 | 实际运行格式化脚本和求解 CLI，检查 NPZ 字段/数组形状/有限值及 JSON 元数据；退出码覆盖 0、1、2 |

默认算例会重复求解，要求电势及电场逐元素一致。所有验收产物均检查边界和有限值；收敛算例还检查最大变化量与离散残差的相容性。网格加密时要求相对离散精确解的误差小于 `2e-8`，以避免迭代误差主导观察阶数。

## 误差如何区分

连续解析解为

\[
\varphi(x,y)=V_0\sin(kx)\frac{\sinh(ky)}{\sinh(kL_y)},\qquad k=\pi/L_x.
\]

解析电场通过直接求导获得：

\[
E_x=-V_0 k\cos(kx)\frac{\sinh(ky)}{\sinh(kL_y)},\qquad
E_y=-V_0 k\sin(kx)\frac{\cosh(ky)}{\sinh(kL_y)}.
\]

均匀正方网格上，离散五点方程的精确模态为

\[
u_{i,j}=V_0\sin(\pi i/n_x)\frac{\sinh(\alpha j)}{\sinh(\alpha n_y)},\qquad
\cosh\alpha=2-\cos(\pi/n_x).
\]

连续解析误差同时包含离散误差与迭代误差；相对离散模态的误差用于单独观察迭代误差。电势误差统计内部节点，电场向量误差覆盖包括边界在内的全部节点。

`tol` 的单位是电势，约束最后两次迭代的最大差值；离散残差的单位是电势/长度²，不能把这两个数值直接等同。网格加密使用更紧的 `tol`，再检查近二阶误差趋势。

## 适用范围

当前矩形输出电势、电场和误差；平行板输出电势、掩蔽电场、描述性比较量和图像，但其外边界及网格敏感性仍待 M2/M3 检查。当前本地核验环境为 macOS arm64、Python 3.11；锁文件支持的其他 Python 版本尚未逐一运行验收。

## 平行板 S3 电场与图像功能检查

测试使用极板两侧梯度不同的分段线性电势，检查相邻自由节点只使用各自一侧的差分、极板上的 NaN 和有效性掩码；均匀场测试独立核对归一化比较量和电压反号。还覆盖中心场方向、端点物理半径掩码、板外点超出计算域、零电压、收敛与未收敛 CLI 结果和三张图像。矢量箭头源点不在极板上，长度归一化，朝极板的箭头会缩短；颜色表示绘出样本的场强。

2026-11-01 起步算例的输出位于 `results/m2-s3-baseline-20261101/`。它仅说明该配置的功能可运行，不证明离散误差、迭代误差或截断误差满足某个精度。端点排除半径为 `0.2d`，代码记录半径是否至少覆盖两个网格区间，作为保守采样提示；仍需 S4 的网格与域检查。

## 平行板 S1–S2 检查与起步耗时

配置测试覆盖几何/极板与网格对齐、板间分辨率、外框间距、非有限值、错误字段和电压符号。求解器测试用含内部固定点的 5×5 网格手算一次更新，并独立验证自由节点残差；还检查固定值保持、对称性、零电压、线性关系，以及实际 CLI 的收敛和未收敛退出码。重构后 M1 数值验收为 47/47 项通过；本地报告在 `results/m1-validation-s2-20261031/report.json`。

2026-10-31 对 `configs/parallel_plate.json` 进行一次起步求解：macOS arm64，Python 3.11.15，NumPy 2.4.6；网格 121×81，`h=0.1`，`tol=1e-9`，`Nmax=100000`。求解调用的墙钟耗时为 **0.303 秒**（含配置校验和网格构造，不含文件写入）；6401 次迭代收敛，最后变化量 `9.9973e-10`，自由节点最大离散残差 `3.9908e-7`。这是单次计时，不是性能基准；完整参数、环境、源码 SHA-256 和输出在本地 `results/m2-s2-baseline-20261031/`。

仅用于后续排期的粗略外推：若每步成本按节点数增长、迭代次数按特征尺度与 `h` 的比值平方增长，则相同外框 `h=0.025` 的网格约 15.8 倍节点、约 16 倍迭代，约 76 秒；最终域 `(a,b)=(12,8)` 且 `h=0.025` 约 62.9 倍节点、约 64 倍迭代，约 20 分钟。极板、收敛阈值、内存访问及机器负载都会改变这些比例；这不是实测耗时或上界。直接按该比例放大迭代次数会超过起步的 `Nmax=100000`，实际运行需检查是否收敛，不能将未收敛结果计为通过。S4 由多次网格、域和阈值运行组成，S5 有五个不同几何，不能把一次起步耗时当成总成本；应先实测中间网格，再规划完整扫描。
