# M1 数值验收

M1 验收覆盖 `rectangle_sine`：二维无电荷 Laplace 方程、均匀正方网格、固定 Dirichlet 边界、五点差分和 Jacobi 迭代。下方记录平行板 S1–S4 的功能与可靠性检查；S4 的网格电场比较尚未达到建议尺度。

## 复现

从项目根目录运行：

```bash
uv sync --locked
PYTHONPATH=src uv run --locked python -W error -m unittest discover -s tests -v
PYTHONPATH=src uv run --locked python -W error scripts/validate_m1.py
```

单元与端到端测试由标准库 `unittest` 执行，数值验收脚本遇到任一检查失败即返回非零退出码。`-W error` 使计算中的浮点警告也会导致本次核验失败。

验收脚本将默认算例、三档网格、三档停止阈值及最大迭代停止算例分别写入 `results/m1-validation/`。顶层 `report.json` 保存输入配置、检查项、误差、观察阶数、Python/NumPy 版本及源码 SHA-256，便于核对所用实现。原始数组和报告不纳入 Git，版本库保存复现所需的代码与说明。

## 验收内容

| 层次 | 检查方法 |
|---|---|
| JSON 接口 | 格式化脚本与配置读写往返；缺失/多余字段、非法类型、非有限参数、网格不可整除与不支持的算例均拒绝 |
| 网格与边界 | 最小 3×3 节点网格、零/负电压；固定四边、左右对称性和离散最大值原理 |
| Jacobi 更新 | 用一次迭代的手算结果排除原地更新；分别验证达到 `tol`、达到 `Nmax` 和最后一次迭代恰好达到阈值 |
| 方程与误差 | 独立计算内部离散 Laplace 残差；核对内部最大误差/RMSE；与离散精确模态比较以分离迭代误差 |
| 电场 | 以已知梯度的二次多项式检查负号、坐标轴和边界；与连续解析电场比较全网格向量误差 |
| 网格加密 | 固定几何与电压，使用 `h=0.1, 0.05, 0.025` 和 `tol=1e-11`；检查电势与电场误差的观察阶数在 1.8–2.2 内 |
| 停止阈值 | 默认网格使用 `tol=1e-6, 1e-8, 1e-10`；阈值收紧应增加迭代次数、减少相对离散精确解的误差 |
| 数值稳定性 | 普通矩形的稳定解析式与直接双曲正弦式一致；纵横比 300 的算例不产生溢出或非有限输出 |
| 输出与退出码 | 实际运行格式化脚本和求解 CLI，检查 NPZ 字段/数组形状/有限值及 JSON 元数据；退出码覆盖 0、1、2 |

默认算例会重复求解，要求电势及电场逐元素一致。所有验收产物均检查边界和有限值；收敛算例还检查最大变化量与离散残差的相容性。网格加密时要求相对离散精确解的误差小于 `2e-8`，以避免迭代误差主导观察阶数。

## 误差如何区分

连续解析解为

\[
\varphi(x,y)=V_0\sin(kx)\frac{\sinh(ky)}{\sinh(kL_y)},\qquad k=\pi/L_x.
\]

解析电场通过直接求导获得：

\[
E_x=-V_0 k\cos(kx)\frac{\sinh(ky)}{\sinh(kL_y)},\qquad
E_y=-V_0 k\sin(kx)\frac{\cosh(ky)}{\sinh(kL_y)}.
\]

均匀正方网格上，离散五点方程的精确模态为

\[
u_{i,j}=V_0\sin(\pi i/n_x)\frac{\sinh(\alpha j)}{\sinh(\alpha n_y)},\qquad
\cosh\alpha=2-\cos(\pi/n_x).
\]

连续解析误差同时包含离散误差与迭代误差；相对离散模态的误差用于单独观察迭代误差。电势误差统计内部节点，电场向量误差覆盖包括边界在内的全部节点。

`tol` 的单位是电势，约束最后两次迭代的最大差值；离散残差的单位是电势/长度²，不能把这两个数值直接等同。网格加密使用更紧的 `tol`，再检查近二阶误差趋势。

## 适用范围

当前矩形输出电势、电场和误差；平行板输出电势、掩蔽电场、描述性比较量和图像。平行板的域大小和网格敏感性已检查，但网格电场差尚未达到建议尺度。当前本地核验环境为 macOS arm64、Python 3.11；锁文件支持的其他 Python 版本尚未逐一运行验收。

测试使用极板两侧梯度不同的分段线性电势，检查相邻自由节点只使用各自一侧的差分、极板上的 NaN 和有效性掩码；均匀场测试独立核对归一化比较量和电压反号。还覆盖中心场方向、端点物理半径掩码、板外点超出计算域、零电压、收敛与未收敛 CLI 结果和三张图像。矢量箭头源点不在极板上，长度归一化，朝极板的箭头会缩短；颜色表示绘出样本的场强。

## 平行板 S4 可靠性检查方法

`scripts/validate_m2.py` 检查固定节点、对称性、最大值范围、中心电场方向及电压反号/倍增线性；在 `h=0.1` 比较 `tol=1e-7、1e-9、1e-11`。计算域从 `(a,b)=(6,4)、(9,6)、(12,8)` 开始；如没有两次相邻扩域比较达到建议尺度，继续检查 `(18,12)、(24,16)`。选取连续两次通过比较中的第一个域，固定几何比较 `h=0.1、0.05、0.025`，再在 `h=0.025` 将该域扩大一次。若没有两次通过的扩域比较，脚本仍记录一个已检查域的网格行为，但不将域检查记为通过。

所有域和网格比较限定在相同物理区域 `[-3,3]×[-1.5,1.5]` 的公共节点，不作插值；使用两板导体和端点 `0.2d` 固定半径排除掩码，并验证两次运行的掩码一致。电势差除以 `|V0|`，电场向量差除以 `Eref=|V0|/d`。建议尺度是迭代阈值比较均小于 `0.1%`，域和网格比较均小于 `1%`；这些是比较尺度，不是开放空间总误差上界。任何一次未收敛、端点区采样标记不满足或比较量超限，都不能作为相应检查通过。

为避免域或网格差异被迭代误差主导，脚本还由自由节点残差计算保守的离散代数误差估计。若残差最大值为 `R`，二次函数及离散最大值原理给出电势迭代误差界 `R min(a²,b²)/2`；在目标区内部节点，中心差分电场的向量误差界取其 `√2/h` 倍。域和网格比较要求两个算例的归一化代数误差界之和均小于 `0.1%`。此界以计算出的浮点残差为依据，没有对舍入误差做严格包络，也不覆盖离散或外框截断误差。

每次运行将配置、收敛状态、计算时间、源码哈希和数值数组保存至 `runs/`，最终 `report.json` 汇总各项检查。`--resume` 只复用配置、源码、后端和数值环境匹配且文件哈希正确的结果。使用可选 Numba 后端时，编译前后均为同一双缓冲 Jacobi 更新，不使用 fast-math；自动化测试将其与 NumPy 后端的一步、多步、收敛和非收敛结果逐项对照。

固定 `(a,b)=(12,8)` 的已完成网格比较中，`h=0.1→0.05` 与 `h=0.05→0.025` 的目标区最大归一化电场差分别约为 `3.52%` 和 `2.07%`，均高于 1% 的建议尺度。后者的最大差异发生在 `(-2.2, 0.45)`，位于极板端点的 `0.2d` 排除区之外；板间中央区域（`|x|≤L/4, |y|≤d/4`）同次比较的最大差异约为 `0.0027%`。中央区域与整个目标区的尺度不同，不能用前者宣称后者已达标。

`results/m2-validation-s4-20261101/grid-field-difference.png` 展示较细两级网格的公共节点电场差、真实极板与端点排除区。以默认验收目录重新生成的命令为：

```bash
PYTHONPATH=src uv run --locked python -W error scripts/plot_m2_grid_comparison.py \
  --coarse results/m2-validation/runs/mesh-h005 \
  --fine results/m2-validation/runs/mesh-h0025 \
  --output results/m2-validation/grid-field-difference.png
```

绘图脚本校验文件哈希、坐标及掩码，要求两次运行收敛、端点排除半径至少覆盖两个网格区间，不对两张网格作插值。

## 平行板 S5 参数扫描方法

`scripts/scan_m2.py` 分别对 `d=1, L=2、4、8` 和 `L=4, d=0.5、1、2` 扫描，共五个几何。各几何使用相同的无量纲外框 `(a/d,b/d)=(12,8)`、电压差 `V0=1`、`tol=1e-11` 和 `Nmax=2000000`；比较 `h/d=0.1、0.05、0.025`，并在 `h/d=0.05` 将外框扩大到 `(18,12)`。每组的目标区域为 `|x|≤L/2+d, |y|≤1.5d`，覆盖整块极板及每个端点外至少一个 `d`。比较在公共节点上进行，不插值，并排除极板与半径 `0.2d` 的端点区域。

复用 S4 的建议尺度：相邻网格和域比较的归一化电势差、电场向量差应均小于 `1%`，两个算例离散代数误差界之和应小于 `0.1%`，且每次运行都必须收敛。每组独立检查；相同的无量纲参数不会自动继承另一组的检查结论。域检查只有一次，且发生在中等网格：即使该次小于建议尺度，也不等于通过 S4 所要求的两次连续扩域及最细网格扩域复查，不能当作开放空间总误差上界。

`report.json` 保存每个算例的输入、节点数、停止状态、残差、运行时间、数值环境、源码和数据哈希以及比较结果；`metrics.csv` 保存描述性指标和可靠性状态。每个网格/域也单独记录中心点与板外点指标，表中列出最后一次网格加密和中等网格扩域的点值变化，便于判断具体观察对这两次比较有多敏感；它们仍不是总误差界。`midline-comparison.png` 比较板间中线场；`potential-comparison.png` 和 `field-comparison.png` 显示无量纲二维分布。电场图屏蔽端点排除区，色标在 `|E|/Eref=2` 截断；不将端点最大场作为收敛指标。中央区域最大偏差使用 `|x|≤L/4, |y|≤d/4`，其物理宽度随 `L` 改变，不能把不同几何的该指标解释成同一固定区域上的误差。

`(L,d)=(2,1)` 与 `(4,2)`，以及 `(8,1)` 与 `(4,0.5)` 分别具有相同的 `L/d`、无量纲外框和网格。脚本还将这两对独立求解的细网格结果在相同的无量纲节点比较；这一缩放一致性检查用于核对参数比较，不能证明其网格或开放空间精度。

执行与断点续算方式见 [README](../README.md)。个别比较超出尺度或算例未收敛时，脚本仍输出诊断并以退出码 `1` 标识；`limited` 表示有未收敛或未通过的比较，`provisional` 仅表示本次有限的比较未超尺度，均不代表完整 S4 验收通过。

## 平行板 S1–S2 检查与起步耗时

配置测试覆盖几何/极板与网格对齐、板间分辨率、外框间距、非有限值、错误字段和电压符号。求解器测试用含内部固定点的 5×5 网格手算一次更新，并独立验证自由节点残差；还检查固定值保持、对称性、零电压、线性关系，以及实际 CLI 的收敛和未收敛退出码。重构后 M1 数值验收为 47/47 项通过；本地报告在 `results/m1-validation-s2-20261031/report.json`。

2026-10-31 对 `configs/parallel_plate.json` 进行一次起步求解：macOS arm64，Python 3.11.15，NumPy 2.4.6；网格 121×81，`h=0.1`，`tol=1e-9`，`Nmax=100000`。求解调用的墙钟耗时为 **0.303 秒**（含配置校验和网格构造，不含文件写入）；6401 次迭代收敛，最后变化量 `9.9973e-10`，自由节点最大离散残差 `3.9908e-7`。这是单次计时，不是性能基准；完整参数、环境、源码 SHA-256 和输出在本地 `results/m2-s2-baseline-20261031/`。

当时仅用于排期的粗略外推：若每步成本按节点数增长、迭代次数按特征尺度与 `h` 的比值平方增长，则相同外框 `h=0.025` 的网格约 15.8 倍节点、约 16 倍迭代，约 76 秒；最终域 `(a,b)=(12,8)` 且 `h=0.025` 约 62.9 倍节点、约 64 倍迭代，约 20 分钟。极板、收敛阈值、内存访问及机器负载都会改变这些比例；这不是实测耗时或上界。后续 S4 和 S5 实测使用可选 Numba 后端并分别记录了实际耗时和收敛状态。
