计划制定日期：2026-10-31。原计划内容保留用于追溯；实际完成情况以实施进度和数值记录为准。

实施进度：S1–S5 已完成。2026-11-01 和 2026-11-04 的较粗网格比较未达到建议尺度；2026-11-08 进一步加密后，五组几何的两次相邻网格比较、连续两次扩域比较和最细网格扩域复查均达到建议尺度。最终检查明确使用多重网格校正生成初值，再执行原五点 Jacobi 停止步骤并检查残差；历史结果与方法差异均保留。具体结果见 [VALIDATION.md](VALIDATION.md)，各阶段完成状态以 [ROADMAP.md](ROADMAP.md) 为准。

## 1. 已确定的范围与建议参数

本次讨论中用户已确定：

- 二维笛卡尔截面：截面内板长有限，垂直截面的方向无限延伸。
- 极板采用零厚度理想导体线段。
- 交付电势、电场、边缘效应比较及数值可靠性记录。
- 外边界采用零电势外框近似开放空间，通过逐步远移外框检查截断影响。

外框是计算截断边界，其尺寸属于数值检查参数；本算例的物理目标为开放空间中的有限长平行板场分布。

其余参数与验收阈值是实现建议，实际试算结果见 [VALIDATION.md](VALIDATION.md)，阈值不构成总误差上界。首版沿用均匀正方网格、五点差分和 Jacobi；不增加电容计算、三维、介质界面或算法性能比较。

## 2. 物理模型与起步参数

坐标以两板几何中心为原点。板长记为 L，板间距记为 d，电压差记为 V0：

- 上板：y=d/2，-L/2≤x≤L/2，φ=+V0/2。
- 下板：y=-d/2，-L/2≤x≤L/2，φ=-V0/2。
- 介质：均匀、无自由电荷，极板以外满足 ∇²φ=0。
- 外框：[-a,a]×[-b,b]，四边 φ=0。
- 电场：E=-∇φ。V0>0 时板间电场主要向下，参考场强 Eref=|V0|/d。

均匀介电常数不影响本次固定电势问题的电势解；首版不引入介电常数输入。统一长度与电压单位，输出注明单位约定；可先以 d=1、V0=1 的参考尺度运行。

建议起步配置：L=4、d=1、a=6、b=4、V0=1、h=0.1、tol=1e-9、Nmax=100000。对应 121×81 个节点、板间 10 个网格区间。它只用于首轮功能和耗时检查，不预先认定域大小或精度合格。

有限零电势外框是一个实际有约束的边值问题；只有域扩大后目标区域稳定，才能将相应结果作为开放空间近似。不能把本模型与“上板 1、下板 0、外框仍为 0”视为单纯更换电势零点：电势平移必须同时平移所有边界值。

## 3. 配置与网格约束

新增 case=parallel_plate，保留现有 rectangle_sine JSON 格式和运行方式。

建议新算例 geometry 使用 plate_length、gap、domain_half_width、domain_half_height；boundary_conditions 使用 V0、outer_potential（首版仅接受 0）。grid 和 solver 继续使用 h、method、tol、Nmax。字段名在实现前统一到配置、输入脚本和说明中。

配置校验必须覆盖：

- 所有数值有限，几何参数和 h 为正；拒绝布尔值冒充数值。
- a/h、b/h、L/(2h)、d/(2h) 在浮点容差内为整数，确保中心、极板端点及两板位置精确落在节点上。用整数索引构造，禁止悄悄吸附或舍入几何。
- 极板完全位于外框内部，与外框至少间隔两个网格区间；板间至少四个区间。该下限只是几何可用性检查，精度仍需加密验证。
- 求解参数沿用现有校验；保留原始输入与实际节点数、端点坐标，便于复核。
- V0=0 可作为零解检查；此时所有归一化指标标记为不适用，不进行除零运算，JSON 使用 null 并说明原因。

## 4. 求解与后处理改动

### 内部固定电势

新增 cases.py，将网格、fixed_mask、fixed_values 和两块独立 plate_mask 作为算例构造结果。外框和极板均为固定节点，其余内部节点为自由节点。

从 solver.py 提取通用 Jacobi 内核：每一步读取旧数组计算五点更新，仅将自由节点结果写入新数组，固定值每轮保持不变。final_change 与离散 Laplace 残差只统计自由节点。极板上的残差不属于无电荷 Laplace 方程验收范围。

保留 solve_rectangle_sine 入口和解析对照逻辑，使 M1 验收能够检查重构是否改变已有行为。矩形结果原有 NPZ 字段和 CLI 退出码继续保持。

### 电场与结果格式

新增 fields.py，保留原矩形梯度计算能力；为电容器增加电场有效性掩码。导体线上的法向场有两侧取值，不能直接把跨两侧的中心差分当作导体表面场。首版不输出表面电荷或导体表面电场。

极板节点上的电场设为无效，使用 field_valid_mask 明示；建议 NPZ 中无效电场填 NaN，JSON 只统计有效值且禁止非有限数值。绘图和分析必须使用掩码，矩形算例仍要求全数组有限。

端点附近单独设分析排除区；在网格比较中采用固定物理半径，例如 δ=0.2d，而非随 h 缩小的“排除几个节点”。如果网格不足以解析排除区，先加密。电场差分模板不跨越导体，端点附近不声称保持整体二阶精度。

电容器 NPZ 保存 x、y、potential、electric_field_x/y、fixed_mask、positive_plate_mask、negative_plate_mask、field_valid_mask；不伪造 analytic_potential 或 absolute_error。summary.json 保存模型、实际几何、收敛状态、自由节点残差、统计区域和输出列表。

### 绘图与比较量

新增 visualize.py，引入 Matplotlib 并更新锁文件。保存以下图像：

1. 电势热图与等势线，标出真实极板和外框，坐标轴等比例。
2. 电场矢量图，稀疏采样、掩蔽导体，保留强度色标。若归一化箭头长度，必须明确说明。
3. 板间中线 y=0 的 -Ey/Eref 随 x/d 变化曲线，标出极板端点。

记录中心场 -Ey(0,0)/Eref、板间中央区域 |x|≤L/4、|y|≤d/4 内相对参考均匀场的最大向量偏差，以及固定无量纲板外点 (x=L/2+d/2,y=0) 的 -Ey/Eref。这些是比较指标，不是有限板解析误差；不预设其严格单调，也不将中心场等于 Eref 作为有限板正确性标准。

极板尖端的最大场对网格敏感，不作为“边缘效应强弱”的主指标或必须收敛的验收量。[COMSOL 关于电磁场尖角奇异性的说明](https://www.comsol.com/blogs/fillet-away-your-electromagnetic-field-singularities)

### S4 可靠性检查

1. **结构与物理检查：** 外框/极板值固定，电势关于 x 偶对称、关于 y 奇对称；V0>0 时电势介于 ±V0/2，板间中心 Ey<0；电压反号或倍增时解按线性关系改变。对称性只能支持实现检查，不能证明边界足够远。
2. **迭代检查：** 同一网格和计算域，比较 tol=1e-7、1e-9、1e-11。记录运行状态和自由节点残差，并比较目标区域电势与电场。tol 约束相邻迭代差，不能冒充解误差。
3. **域大小检查：** 固定几何、h 和足够紧的迭代设置，将 (a,b) 从 (6,4) 扩为 (9,6)、(12,8)。在同一固定物理目标区 [-3,3]×[-1.5,1.5] 比较，排除导体及固定半径端点区。用 Δφ/|V0|、|ΔE|/Eref 的最大值度量差异，避免在零场点用局部相对误差。若迭代误差尚未足够小，先收紧迭代再比较。
4. **网格检查：** 固定已检查的计算域与几何，比较 h=0.1、0.05、0.025，在共同节点和同一固定物理排除区统计差异。不要求尖端场或全域最大场呈二阶收敛。随后在最终网格复查一次域扩大影响，防止只在粗网格上得出边界无影响的结论。
5. **建议验收尺度：** 起步以目标区域归一化电势差和电场差均小于 1% 为网格/域比较目标，并检查两次相邻加密或扩域比较；迭代收紧造成的差异目标小于 0.1%。这些是课程算例的建议精度，不是严格误差上界；未达标则继续加密/扩域，或明确报告限制，不按阈值反改记录。

扩大域时固定网格间距的做法参考 [COMSOL 官方边缘场算例](https://doc.comsol.com/6.4/doc/com.comsol.help.models.acdc.capacitor_fringing_fields/capacitor_fringing_fields.html)。该来源是三维有限元模型，仅支持域敏感性方法，不作为本二维零厚度算例的数值基准。

### S5 参数扫描

- 板长扫描：固定 d=1，L=2、4、8。
- 板间距扫描：固定 L=4，d=0.5、1、2。
- 两组共享 L=4、d=1 基准，合计五个几何配置；优先做一维扫描，避免立刻铺开全组合。
- 使用 x/d、y/d、φ/V0、E/Eref 比较；改变 d 时保持相当的 h/d，避免把网格分辨率变化误判为物理变化。
- 每个几何分别检查域大小与分辨率；可复用已验证的保守计算域，但不能自动继承基准的验收结论。实际域应覆盖极板外至少一个 d 的主要观察区。
- 扫描结果只报告实际获得的变化，理论趋势用于解释，不作为强制通过的单调性断言。
