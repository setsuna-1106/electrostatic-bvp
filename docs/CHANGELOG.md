# Changelog

记录项目中值得追踪的功能、文档和行为变化。

## [Unreleased]

### Added

- 增加有限长零厚度平行板配置、对齐及最小间距校验、网格与极板固定节点构造。
- 新增 [M2-PLAN.md](M2-PLAN.md)，记录平行板算例的范围与参数、配置约束、求解与后处理改动及分阶段验收标准，并标注 S1/S2 已实现。
- 增加通用固定节点 Jacobi 求解，将平行板电势、几何和自由节点诊断写入 NPZ/JSON。
- 增加平行板电场有效性和端点排除掩码、无量纲比较量，以及电势等势线、电场矢量和中线曲线图；零电压的归一化指标标为不适用。
- 增加 S4 平行板可靠性检查、可恢复的算例记录、共同节点与端点排除区比较，以及网格电场差异诊断图；原先三档网格的电场比较未达到建议尺度。
- 增加 S5 板长与板间距扫描，保存各几何的网格及扩域检查、无量纲指标表和场分布比较图；支持校验来源后复用基准与断点续算。
- 增加最终细网格与扩域复查脚本：以多重网格校正构造初值，再执行原有 Jacobi 更新和独立残差检查；保留完整电势及可核验的配置、环境、来源哈希和断点续算。
- 增加最终细网格的电势和电场对比图及绘图来源清单，明确显示采样间距与目标区的适用范围。

### Changed

- 矩形算例复用通用内核，并保留解析对照、原有输出字段和退出码；M1 数值验收覆盖新增算例构造模块。
- 电场计算拆分至 `fields.py` 并保留原入口；引入 Matplotlib 绘图依赖。
- 增加可选的 Numba 编译后端，加快相同 Jacobi 更新；NumPy 仍为默认后端。
- 五组平行板几何在进一步加密后达到 M2 的建议网格和扩域比较尺度；保留较粗网格未通过记录，并限定有限外框的结论。
- 本地 `output/`（阶段汇报等生成材料）与 `.mimosa/`（安全扫描工具状态）目录加入忽略列表，生成物继续不纳入 Git。

## [0.2.0] - 2026-10-24

M1 MVP：完成矩形区域求解、电场数值输出和可重复的数值验收。

### Added

- 新增矩形正弦算例的 JSON 配置读取与基础参数校验，并提供可复用同一校验逻辑的轻量格式化脚本和默认配置文件。
- 新增矩形均匀网格、固定 Dirichlet 边界、五点 Jacobi 求解与解析解对照；求解结果包含收敛状态、迭代次数、最终变化量及内部节点误差指标。
- 新增数值运行入口，将网格、电势、解析解、绝对误差与电场分量保存到 `solution.npz`，并将网格参数、收敛信息、离散 Laplace 残差和解析误差指标保存到 `summary.json`。
- 新增二阶电势梯度电场计算，明确 `(y, x)` 数组轴顺序及边界差分方式。
- 新增配置、求解器和命令行测试，以及生成本地网格加密、阈值敏感性和离散精确解对照记录的 `scripts/validate_m1.py`。
- 新增 [VALIDATION.md](VALIDATION.md)，记录验收方法、复现命令与适用范围。

### Changed

- 调整[开发路线图](ROADMAP.md)：先验证矩形区域解析算例，再研究平行板边缘场，并检查网格、迭代阈值和计算区域的影响；COMSOL 对照作为条件性扩展。
- 更新[项目说明](../README.md)，同步研究范围、当前数值输出能力和默认算例运行命令。
- 在[开发路线图](ROADMAP.md)中补充目标目录结构、模块职责和 JSON 输入流：格式化脚本生成算例配置，主程序读取并构造求解器输入；JSON 保存配置参数，不承载计算数组。
- 同步 M1 完成状态；矩形网格与阈值检查已完成，电容器与计算域敏感性继续按后续阶段推进。
- 运行依赖缩减至 NumPy，移除当前未使用的 Matplotlib 与 SciPy；`results/` 中的生成物不纳入 Git。

### Fixed

- 使用指数形式稳定计算双曲正弦比，避免高纵横比矩形的解析解对照出现 `sinh` 溢出。
