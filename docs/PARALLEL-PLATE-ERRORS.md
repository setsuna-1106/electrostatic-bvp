# 平行板误差分析

本次检查的是二维、均匀介质中的两块有限长零厚度极板：板长 `L=4`、间距 `d=1`、电势 `±V0/2`、`V0=1`。如果物理目标是**开放空间**，原配置的矩形接地外框就会改变解；如果研究的恰好是有接地屏蔽的装置，则应保留该边界。有限长极板在板外确实有场，板间也不必处处满足无限长极板的 `Ey=-V0/d`。

## 怎样把几个因素分开

- **迭代**：固定 `h=0.1` 与半宽、半高为 `(6,4)` 的外框，改变 Jacobi 的停止阈值。最后两步之差 `tol` 只用于停止，不能代替实际解差。
- **外框**：保持同一网格和五点方程，仅将接地外框上固定的零改为开放空间解在该处的电势。另用仍接地但扩到 `(12,8)` 的计算作对照。
- **网格**：用开放空间电势约束外框后，在 `h=0.1、0.05、0.025` 上分别求解，再与开放空间电场比较。把开放空间电势直接采样后作中心差分，可以进一步分开电势离散与求梯度两种影响。各误差最大值可能发生在不同位置，而且向量误差可能部分抵消，表中最大值不能相加。
- **板端**：零厚度板端处，邻域张角为 `2π`，电势的主导变化按 `√r` 缩放，电场随 `1/√r` 增长；因此靠近端点时五点差分的光滑性假设减弱。加密网格可以改善固定位置的场，却会采到更接近端点、值更大的场，不能用全域最大场验收。若需要实际尖端的最大场，要给出真实厚度和圆角半径。

比较在 `|x|≤3、|y|≤1.5` 中间距为 `0.1` 的公共节点上进行，无插值；排除极板及距四个板端不超过 `0.2d` 的节点。场差为电场向量差模除以 `Eref=|V0|/d`，电势差除以 `|V0|`。中央区域另取 `|x|≤L/4、|y|≤d/4`。

| 对照 | 最大电势差 | 最大电场向量差 |
|---|---:|---:|
| 原配置与开放空间参考解 | 5.034% | 8.503% |
| 原外框，`tol=1e-9→1e-11` | 0.0000369% | 0.0000472% |
| 仍接地，外框 `(6,4)→(12,8)`，`h=0.1` | 3.929% | 4.115% |
| 同一外框，仅以开放空间电势替代零边值，`h=0.1` | 5.144% | 5.541% |
| 已修正边值的差分解与开放空间解，`h=0.1` | 1.705% | 5.809% |
| 同上，`h=0.05` | 0.858% | 3.033% |
| 同上，`h=0.025` | 0.428% | 1.555% |

原配置的最大场差出现在板端附近；板间中央区域的最大场差只有 `0.0072%`。边值修正后，残余场差大体随步长减半而减半。粗网格上，仅对参考电势作中心差分带来 `1.614%` 的最大场差；差分解与该粗网格电势样本之间的电势偏差，传到场上带来 `6.039%` 的最大差。只提高电场求导的阶数，不能解决这次粗网格的主要问题。

开放空间解给出中心点 `-Ey/Eref=0.9999974`，板外点 `(2.5,0)` 则为 `0.3600404`。板外场本身反映边缘效应。[此前 M2 最终记录](VALIDATION.md#2026-11-08m2-最终网格与计算域复查)中，同一几何在 `h/d=0.005`、接地框 `(12,8)` 下的板外点值为 `0.3543453`，与这里的开放空间参考值相差约 `0.00570 Eref`。此前相邻网格和扩域比较通过，只能约束那些比较的差异。

## 开放空间求解

主程序新增 `--open-space`。两板关于 `y=0` 反射反号，所以上板与下板的线电荷密度互为相反数。用二维 Laplace 对数格林函数表示电势，上、下两条线源的对数远场项抵消，电势在无穷远趋于零。设 `A=L/2`，令源坐标 `x'=A cos θ`，把 `1/√(A²-x'²)` 端点权重吸收到积分变量中，剩余平滑密度用余弦级数表示。上板的自作用对数核在余弦基底中对角化，另一块板的核光滑，使用中点求积；随后直接从积分表示式求电势和电场。开弧对数核的处理可参阅 [Bruno 与 Lintner 的论文](https://agupubs.onlinelibrary.wiley.com/doi/abs/10.1029/2012RS005035)。

逐次加倍展开阶数，直到单位电压下的板上采样误差和相邻电荷系数的相对变化均不超过 `1e-11`。检查在板上加密采点进行，包含端点。测试还用直接对数核求积交叉检查电势和电场的计算公式，并检查远场衰减、端点缩放和输出窗口独立性。这些是稳定性和一致性证据；它们不构成整个开放空间的严格误差界，也未与 COMSOL 或实验装置对照。

## 复现

```bash
PYTHONPATH=src uv run --locked python -m electrostatic_bvp.main \
  --config configs/parallel_plate.json --open-space
PYTHONPATH=src uv run --locked --extra s4 python scripts/compare_plate_errors.py
```

第二条命令在 `results/plate-error-analysis/` 输出 `report.json` 和 `field-error-comparison.png`。图上的三张误差图共用色标；白色区域为导体和板端排除区。
